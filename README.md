# Python Fundamentos

Repositório dedicado aos meus estudos dos fundamentos da linguagem Python e à prática de lógica de programação por meio de exercícios.

Grande parte dos exercícios foi desenvolvida durante meus estudos com o curso de Python do [Curso em Vídeo](https://www.cursoemvideo.com/), ministrado pelo professor Gustavo Guanabara.

## Progresso

Atualmente, o repositório reúne **mais de 90 exercícios**, mantidos em sequência para registrar minha evolução ao longo do aprendizado.

## Objetivo

Reforçar e consolidar os conteúdos estudados em Python por meio de prática constante, resolução de problemas e versionamento do código com Git e GitHub.

## Conteúdos praticados

- Entrada e saída de dados
- Variáveis e tipos de dados
- Operadores
- Manipulação de strings
- Estruturas condicionais
- Estruturas de repetição
- Listas, tuplas e dicionários
- Funções
- Módulos e bibliotecas
- Tratamento de erros com `try` e `except`

## Exercícios

A pasta [`exercicios`](./exercicios) reúne os códigos desenvolvidos durante meus estudos.

Os arquivos são mantidos em sequência para preservar a progressão dos exercícios e permitir acompanhar minha evolução. Alguns números podem não existir porque a sequência acompanha os exercícios efetivamente realizados durante o curso.

## Como executar

Com Python 3 instalado, clone o repositório e execute o exercício desejado pelo terminal:

```bash
git clone https://github.com/marcosvs11/python-fundamentos.git
cd python-fundamentos
python3 exercicios/exercicio-90.py
```

A maior parte dos exercícios utiliza somente a biblioteca padrão do Python. O exercício que reproduz áudio utiliza `pygame`, disponível em [`requirements.txt`](./requirements.txt):

```bash
python3 -m pip install -r requirements.txt
```
