# Python Fundamentos

Repositório dedicado aos meus estudos dos fundamentos da linguagem Python e à prática de lógica de programação por meio de exercícios.

Grande parte dos exercícios foi desenvolvida durante meus estudos com o curso de Python do Curso em Vídeo, ministrado pelo professor Gustavo Guanabara.

## Objetivo

Reforçar e consolidar os conteúdos estudados em Python por meio da prática constante de exercícios.

Este repositório também funciona como registro da minha evolução com a linguagem.

## Conteúdos praticados

- Entrada e saída de dados.
- Variáveis e tipos de dados.
- Operadores.
- Manipulação de strings.
- Estruturas condicionais.
- Estruturas de repetição.
- Listas, tuplas e dicionários.
- Funções.
- Módulos e bibliotecas.
- Tratamento de erros com `try` e `except`.
